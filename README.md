# Terraform Lab

This repository contains assignments for learning Infrastructure as Code using Terraform.

## Structure

- day1: Introduction to Terraform (local file creation)
- day2: Variables and tfvars usage
- day3: Docker container using Terraform
- day4: Terraform modules for reusable infrastructure
- day5: CI/CD using GitHub Actions

## Tools Used

- Terraform
- Docker
- Git & GitHub

## Workflow

terraform init → terraform plan → terraform apply → terraform destroy
